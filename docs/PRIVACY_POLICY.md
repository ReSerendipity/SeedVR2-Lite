# SeedVR2-lite 隐私政策

**生效日期**：2026-09-02 ｜ **版本**：v1.0

SeedVR2-lite 是一款自托管的图像/视频修复（Restore）工具。我们遵循"本地优先、最小收集"原则，本政策说明数据处理方式。

## 1. 本地数据（默认不上传）

| 数据类型 | 处理方式 |
|---|---|
| 上传素材（图像/视频） | 仅存储于本地，用于本次修复处理，不上传任何服务器 |
| 修复结果（图像/视频） | 保存于本地输出目录，由您自行管理 |
| 历史记录（任务、修复记录） | 存储于本地数据库（SQLite），可随时清空 |
| 水印密钥、配置 | 存储于本机配置与密钥文件，不随仓库分发 |
| 完整性清单签名密钥（data/.manifest_signing_key） | 仅存构建/签发机与 CI Secret，不随仓库与发布包分发，需离线备份 |

## 2. 推理引擎的数据流向

- **默认（本地推理）**：修复在您本机 GPU 完成，素材与结果均不出设备；
- **可选远程部署**：若您将服务部署到局域网/公网，访问者提交的素材由您的部署处理，请自行评估相关合规要求。

## 3. 我们不收集的内容

本服务**不收集**任何个人信息、使用埋点或遥测数据；不依赖第三方分析服务。

**第三方资源披露**（2026-09-06 更新）：界面基础字体（DM Sans / Instrument Serif）
已本地化，页面默认加载**不向任何第三方发起请求**。仅当您主动展开「标题字体」
菜单或此前已选用装饰字体时，浏览器才会向 Google Fonts
（fonts.googleapis.com / fonts.gstatic.com）请求所选字体资源（属内容加载，
非数据上报；网络不可达时界面会明确提示，不会静默降级）。

## 4. 数据删除

删除本地上传目录、输出目录与历史数据库即可清除全部数据。

## 5. 政策更新

本政策如有变更将在本页面同步更新并标注版本号。
